# s-genussplatzl.at

Website des s’Genussplatz’l in Unterpurkla (statisch, GitHub Pages).

- Bauen: `python tools/site.py` (erzeugt index.html, radrouten/, gpx/, sitemap.xml aus layout.html + pages/)
- Bike-&-Spa-Karte: `python tools/bikespa_map.py`, danach neu bauen
- Vorschau-Ordner zum Doppelklicken: `python tools/export.py <ziel>`
- Umami: Website-ID in tools/site.py (UMAMI_ID) eintragen und neu bauen

Routen: BRouter auf OpenStreetMap-Daten, © OpenStreetMap-Mitwirkende (ODbL).
